Connect DailyBudget to Supabase

This copy of the app isn't connected to a database yet, so sign-in is turned off.

  1. Create a free project at supabase.com.
  2. Run supabase_setup.sql in the Supabase SQL Editor.
  3. Copy the Project URL and the publishable (or anon) key from Project Settings → API.
  4. Open index.html, find SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY, and paste them in.
  5. Upload the updated file to GitHub and reload this page.

Never paste the service-role key or your database password into this file.

Private by design

  • Your records are stored in a database protected by row-level security. Only your signed-in account can read or change them.
  • DailyBudget never asks for bank logins or card numbers.
  • Your financial data is not sent to any AI or analytics service.
  • Balances are calculated from what you enter. They are estimates, not bank-verified figures.
